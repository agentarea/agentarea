# agentarea

Short alias for the AgentArea CLI. This package simply re-runs
[`@agentarea/cli`](https://www.npmjs.com/package/@agentarea/cli).

```bash
npx agentarea
```

Equivalent to:

```bash
npx @agentarea/cli
```

For the full CLI source, docs, and issues see the
[`@agentarea/cli`](https://www.npmjs.com/package/@agentarea/cli) package and the
[AgentArea repository](https://github.com/agentarea/agentarea).
